# 🌿 EcoRoute EV – Smart Electric Vehicle Route Planner

EcoRoute EV is an AI-powered Electric Vehicle (EV) route planning and energy optimization application built using Python and Streamlit.

The application helps EV users plan journeys, estimate energy consumption, explore charging stations, compare routes, and understand the environmental benefits of electric vehicles.

## 🚗 Key Features

- **Smart Route Planner** – Plan EV journeys and explore route options.
- **Energy Prediction** – Estimate energy consumption using Machine Learning.
- **Weather-Based Energy Prediction** – Understand how weather conditions may affect EV energy usage.
- **Charging Station Locator** – Find nearby EV charging stations on an interactive map.
- **Charging Availability Checker** – Explore charging station information and availability-related details.
- **Smart Charging Stop Planner** – Identify potential charging stops during a journey.
- **Trip Cost Calculator** – Estimate charging costs based on energy consumption and electricity tariffs.
- **Carbon Emission Savings Calculator** – Estimate environmental benefits compared with conventional vehicles.
- **Energy Consumption Comparison** – Compare energy usage across trips and routes.
- **Advanced Analytics Dashboard** – Explore trip statistics and energy insights.
- **Personalized EV Dashboard** – View personalized trip and energy information.
- **Local AI EV Assistant** – Get answers to common EV-related questions without requiring a paid API key.
- **Trip History** – Store and review previous trip information.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/omghello4646-source/EcoRoute-EV.git
```

### 2. Navigate to the Project Folder

```bash
cd EcoRoute-EV
```

### 3. Install Dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the Application

```bash
streamlit run app.py
```

## 🌍 Data and Limitations

- Charging station information may be retrieved from OpenStreetMap services.
- Internet access is required for external map and weather data.
- Station listings do not guarantee real-time charger availability.
- Energy predictions are estimates and may vary from actual vehicle performance.

## 🎯 Project Objective

The objective of EcoRoute EV is to make electric vehicle travel more convenient through route planning, energy prediction, charging station discovery, and sustainability insights.
